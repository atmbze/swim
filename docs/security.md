# Security notes
See ASSESSMENT.md §6 for findings by severity. Controls in place: bcrypt hashing; hashed opaque session tokens with 7-day expiry; HttpOnly/SameSite=Lax/Secure cookies; Origin-header check on mutating requests; server-side ownership/role checks in every service; zod validation; image type detection by magic bytes with 2 MB cap and random filenames; parameterized SQL everywhere (dynamic column names come only from zod-validated keys); `X-Frame-Options: DENY`, `nosniff`, referrer policy. Missing: rate limiting, CSP, CSRF tokens, email verification, password reset, audit log.
